# Дневник смен водителя

Небольшое веб-приложение для учёта поездок водителя за смену: API на Express и простой клиент в браузере.

## Возможности

- **GET `/api/trips?date=YYYY-MM-DD`** — список поездок за день и сводка:
  - число поездок
  - выручка
  - комиссия
  - «на руки» (выручка − комиссия)
  - разбивка наличные / карта
- **GET `/api/dates`** — дни, по которым есть поездки
- **POST `/api/trips`** — добавление поездки с проверками:
  - `amount > 0`
  - `end` позже `start`
  - `payment`: `cash` | `card`
  - повторная отправка той же поездки **не создаёт дубль** (по `id` или по полному совпадению полей)
- Веб-клиент: сводка, список поездок, переключение дней, форма добавления

## Быстрый старт

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

Данные лежат в `data/trips.json`.

## Тесты

```bash
npm test
```

Покрыто:

- расчёт сводки (`tests/summary.test.js`);
- валидация и защита от дублей через API (`tests/trips.test.js`).

## Структура

```
src/
  server.js      # Express API + раздача статикой
  store.js       # чтение/запись JSON, фильтр по дню
  summary.js     # расчёт сводки
  validation.js  # валидация и сравнение поездок
public/          # веб-клиент
data/trips.json  # исходные данные
tests/           # vitest + supertest
```

## Пример запроса

```bash
curl "http://localhost:3000/api/trips?date=2026-10-01"
```

```bash
curl -X POST http://localhost:3000/api/trips \
  -H "Content-Type: application/json" \
  -d '{
    "id": "t6",
    "start": "2026-10-01T14:00:00+05:00",
    "end": "2026-10-01T14:20:00+05:00",
    "amount": 2000,
    "payment": "cash",
    "commission": 300
  }'
```

При повторной отправке того же тела ответ будет `200` с `"created": false`, список поездок не вырастет.
